# Ladies and Gentlemen Codex

This repository contains the **Gentleman's Code** and the **Lady's Code**, maintained as living texts in multiple languages.

The codes draw on enduring traditions of honour, dignity, self-command, responsibility, courtesy, good character, courage, fairness, discretion, hospitality, and respect for others, while expressing those principles in terms that can be applied to contemporary life.
